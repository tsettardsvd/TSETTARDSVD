# TSETTARDSVD — Premium Jewelry & Watches Website

A polished, responsive editorial storefront concept for TSETTARDSVD.

## Open locally
Open `index.html` in a browser. No build tools required.

## Publish with GitHub Pages
Upload all files and the `assets` folder to the root of a GitHub repository. In **Settings → Pages**, select **Deploy from a branch**, `main`, `/(root)`. The site supports repository subpaths because its asset paths are relative.

## Features
- Editorial homepage with large photographic hero
- Jewelry and watch collection navigation
- Eight illustrated products, search, filtering and sorting
- Browser-local wishlist and shopping bag with removable items
- Mobile navigation and responsive layout
- FAQ, privacy and terms pages
- No build step, backend, checkout, or third-party JavaScript libraries

## Important
This is a **concept / demo**, not a real e-commerce store. Prices, products, availability and shopping bag are illustrative. No purchases or messages are processed. Product imagery is remotely loaded from Unsplash and fonts from Google Fonts, so an internet connection is needed for those assets. Replace illustrative photos with properly licensed brand product photography before a commercial launch.
